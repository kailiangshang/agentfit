当前有效设计请阅读：

- [AgentFit 整体架构与方法论](../../architecture/agentfit-methodology.md)

- 将 Agent 与 Skill、Tool、Memory 并列视为普通能力节点；
- 未区分能力图与 Agent 分区；
- 将项目内双层优化直接称为 Meta-learning；

因此，归档文档只能作为决策历史和研究素材，不能覆盖当前规范中的定义、边界与证据等级。
