# AgentFit 设计历史归档

本目录保存 AgentFit 早期讨论、理论推演、框架调研和仓库治理决策。它们用于解释方案形成过程，属于非规范性历史材料。

唯一当前方案：

- [AgentFit 整体方案](../../agentfit-solution.md)

其他归档类别：

- [`../superseded-design/`](../superseded-design/)：被当前方案取代的旧方法论和执行设计；
- [`../superseded-plans/`](../superseded-plans/)：已经执行或失效的路线图和阶段计划；
- [`../execution-plans/`](../execution-plans/)：已批准的仓库治理和实施计划。

归档内容可能包含以下已被修正、尚未验证或已经退役的观点：

- 将 Agent 与 Skill、Tool、Memory 并列为普通能力节点；
- 未区分能力图与 Agent 分区；
- 将项目内双层优化直接称为 Meta-learning；
- 依据同步 Python 模拟器推断真实 AgentTeams 能力；
- 尚未完成的 Agent Identity、Skill、评测和工程实现设想；
- 已被后续证据、用户决策或唯一方案替代的执行顺序。

归档文件只能作为决策历史和研究素材，不能覆盖当前方案的定义、边界、完成状态与证据等级。
