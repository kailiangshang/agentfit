05 / 12 · LAYERED SOLUTION SPACE

方案空间按四层资产组织，调整逐层受控。

七个方案维度不再并列漂浮：工具、Skill、MCP、Memory、模型、Agent 拓扑与 Human 边界各归其层。

L1 · SOLID

原子接口 · 固定资产（知识库 / 查询 / CMDB）

全局共享；无复杂可配置参数；受控生长（观察区 + 升格门限）

L2 · TOOL / MCP

source tool 封装 · 唯一合法触达 L1 的层

聚合、分析、切片的口径在此唯一定义；模型等参数在此校准

L3 · SKILL / MEMORY

可复用知识 · 排查链、问题路由、人工门限

可变；每次变更绑定证据并通过回归池门；可晋升共享

L4 · DAG

Agent 组合与流程 · Agent 拓扑与 Human 边界

结构变更需影子模式验证；责任分区在此定义

触达纪律 · 代码强制

1 知识层不得直接调用接口层

2 聚合分析必须经 source tool 二次封装

3 知识产出只供 Agent 消费

4 共享范围随层递减，Solid 全局但原子化

5 越层依赖在 schema 校验即拒

不是 prompt 自觉，是 checker 拒绝

L4 拓扑谱系 · 只是其中一维

C1 · 单 Agent

C2 · 多 Agent

C3 · Human 混合
