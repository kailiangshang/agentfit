下层 · 候选业务执行 Agent（被设计的对象）

C0 无；C1 一个；C2 多个，OpsPilot 的 Alert Intake / Commander / RCA Analyst / Data Advisor / Planner / Executor / Verifier 属于这一层；C3 由 Human 承担高风险动作。

五个元 Agent 不是 OpsPilot 的执行 Agent；它们负责选出“该不该有执行 Agent、有几个”。

一个元 Agent 不可用时阶段保持未完成，其他 Agent 不得冒充它的责任产物。
