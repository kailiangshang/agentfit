Agentize/拆分/合并 · 无↔单↔多迁移

ProjectAsset→MetaAsset · 越用越聪明

范式转换主张

深度学习用学习替代手工特征(SIFT/HOG)
NAS 用搜索替代手工设计网络(VGG/ResNet)
AgentFit 用搜索+学习替代手工设计 Agent

Agent 架构,正处在"手工设计特征"的时代。该发生的范式转换,正在发生。

主张三句话

① Agent 数量是搜索变量,不是先验目标——每多一个 Agent 必须证明边际价值
② 合法结果有五种:全自动 / 部分 / 降级 / 保留人工 / 拒绝自动化——拒绝也是合法交付
③ 元学习必须跨项目验证:单项目搜索 ≠ 元学习,迁移 ≠ 元学习,先验更新+未见验证才是
