# AgentFit 作品简介

> 状态：初赛提交候选。正文按非空白字符计数不得超过 500；完成态只引用仓库内可核验事实。

## 核心主张（一句话）

**AgentFit 是运行在 AgentTeams 上的 Agent 方案建筑师：给业务任务量体裁衣，找到“刚好够用”的方案。**

## 500 字以内作品简介

企业用 Agent 改造业务时，困难往往不是模型或框架，而是判断该不该自动化、用几个 Agent、如何协同、怎样验收。重平台要求团队先理解组件，轻框架又把业务拆解、方案设计和评测留给开发者。

AgentFit 是运行在 AgentTeams 上的 Agent 方案建筑师。它先从材料中定义可重放、可验收的业务样本，再编译含输入、输出、指标、预算、风险和 Human 边界的任务语义，然后把模型、规则、Skill、MCP、工具、记忆与人工编译为能力语义，生成 Agentless、单 Agent、多 Agent和人工混合候选，让它们在同一冻结样本集、预算、安全门禁和验收线下比较，以最小复杂度选择合格方案。

交付官、业务架构师、方案架构师、验证工程师和审计官组成责任闭环；AgentTeams 提供身份、通信、容器、权限与共享能力，AgentFit 负责方案选择、证据和审计。最终交付可部署、可复验、可回滚的方案包，也可以有证据地保留人工或拒绝自动化。

当前已完成方法、Identity、Skill、风险契约、官网案例拆解和软件研发设计模拟；真实运行证据仍待补，不把设计模拟或历史平台测试写成 AgentFit 成果。
