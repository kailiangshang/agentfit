七层 ML 映射、候选四元组与内外循环。

主线是方案选择；这里的 ML 语义只是后台手段。Meta-learning 是未来方向，当前未实现。

SEVEN-LAYER MAPPING · 七层 ML 映射

L1 样本语义 → 样本单位、边界、重放与标注契约

L2 任务语义 → 分布、输出、指标、损失与权衡

L3 能力语义 → 算子集、契约、权限与适用域

L4 候选表示 → 结构、分区、参数与共享范围

L5 内循环（inner loop）→ adaptation samples 上优化局部参数

L6 外循环（outer loop）→ validation samples 上比较候选架构

L7 跨项目学习 → 未见项目验证后更新搜索先验

L7 是未来方向：单项目样本优化不能证明跨项目学习。

候选四元组

Candidate = (G, Π, θ, ρ)

G 能力图 · Π Agent 分区 · θ 模型/Prompt/阈值 · ρ 状态与记忆共享范围

INNER LOOP · 一个 epoch 内

让局部 Agent 变好

固定 G / Π；更新 θ / ρ；遍历 adaptation samples。

inner loop 服务于方案选择

OUTER LOOP · 架构 epoch

让整体任务结果变好

更新 G / Π；比较 validation samples；保留合格候选。

不预设多 Agent 胜出

META-LEARNING 未来边界

项目内参数优化与架构搜索不等于 Meta-learning；只有多个项目轨迹更新先验、并在未见项目上稳定改善，才构成 Meta-learning 证据。

机器可执行 Schema、自动候选搜索与跨项目 Meta-learning 当前均未实现；设计契约，非运行证据。
