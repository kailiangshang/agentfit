# AgentFit 路演大纲

## 主题

Agent 协同在真实场景下的落地：怎么保证可审计、可追溯、可维护、可量化

## 12 页主路演

| 页 | 标题 | 内容要点 |
|---:|---|---|
| 1 | 企业真正缺少的，是选对 Agent 方案的方法 | 问题定义：该不该自动化？什么架构？怎么证明？ |
| 2 | AgentFit：方案不是设计出来的，是训练出来的 | 核心范式转变 |
| 3 | 四层骨架：Solid → 能力 → 知识 → 拓扑 | 架构定义 + 逐层依赖铁律 |
| 4 | 存在依赖：每个能力追溯到物理基础设施 | 强约束 + 无幻影能力 |
| 5 | 训练循环：执行→归因→更新→回归→迭代 | 完整闭环 |
| 6 | 自底向上归因：错在哪层、为什么、怎么修 | 反向归因算法 + 因果性验证 |
| 7 | 正则约束：可维护性从口号变成数字 | 16 指标 + 4 权重 + 两级 λ 调节 |
| 8 | 可审计：训练日志（哈希链保护） | 每轮通过率/损失/更新/回归/成本 |
| 9 | 可追溯：失败→根因→修复→验证 | 损失轨迹全链路 |
| 10 | 可量化：通过率/成本/正则值/回归率 | 数字说话 |
| 11 | Telecom 实测：80% baseline → AgentFit 目标 | 场景验证 |
| 12 | 五种合法交付：包括"拒绝自动化" | 诚实交付边界 |
