# AgentFit 作品简介

## 核心主张（一句话）

**AgentFit 是一个面向复杂任务的 Agent 基础设施与方案训练系统：输入业务场景和样本，输出经过多轮训练、通过率验证、边界明确的可部署 Agent 方案。方案不是设计出来的，是训练出来的。**

## 500 字以内作品简介

企业提供业务材料和真实样本，但不知道该不该用 AI Agent、该用什么架构、效果有多好。AgentFit 把这个问题变成一个可量化的训练过程：从最简方案开始，在真实样本上执行，对失败样本自底向上归因到四层架构（Solid 原子→安全封装→可复用知识→行为拓扑）的具体层和具体元素，聚合损失后生成更新建议，人工审核后以原子事务应用更新，回归验证确保不遗忘，迭代到收敛。最终交付可部署方案包、完整训练记录、适用边界和持续监控配置。

四层架构保证天然可维护：纵向逐层调用不可跨层，横向同层禁止执行时互调，存在依赖要求每个能力追溯到物理基础设施。正则约束将"可维护性"量化为 16 个指标和 4 个权重，防止单点耦合爆炸。

五种合法交付：全自动、部分自动化、降级、保留人工、拒绝自动化。"不自动化"和"自动化"一样是合法结论，且有证据支撑。

在 telecom 故障诊断场景下，τ²-bench 基准 10 样本实测通过率 80%，成本 $0.006/样本。AgentFit 的目标是通过训练超过裸跑 baseline，同时提供 baseline 不具备的可审计、可追溯、可维护、可量化四项保证。

## 技术要点

- 四层骨架：L1 Solid（固定原子，含人工审核）→ L2 可二次开发能力（工具调用安全封装+送审路由）→ L3 可复用知识（Skill+路由+排查链实现任务拆解+经验）→ L4 行为拓扑（多 Agent 协同+上下文传递+人工介入）
- 内部架构：AgentFit 自身即六角色多 Agent 协同（交互/编排/归因/架构/验证/审计分权 + 消息因果链，覆盖从用户提交材料到交付的全链路）；验证与审计为纯确定性代码保证裁决可复现，LLM 仅用于材料操作化、归因消歧与建议生成（版本化、计量、低置信度升级人审）
- 训练循环：前向执行→自底向上归因（含因果性验证）→正则计算→分层更新建议→λ两级调节→人审→原子事务应用→回归验证→训练日志
- 评价指标：通过率、成本/样本、各层损失分布、正则值、回归通过率、人工介入率
