# 风险与人工门禁设计

## 设计原则

人工审核是 L1 的标准原子（与 API 调用同级），L2 负责送审路由（术业有专攻），L3 负责触发条件，L4 负责在拓扑中的位置。

## 人工门禁分类

| 门禁类型 | 触发条件 | 审核人 | 超时处理 |
|---|---|---|---|
| 财务审批 | 金额 > $100 | 财务团队 | 超时升级主管 |
| 安全审批 | 异常账户/危险操作 | 安全团队 | 超时阻断 |
| 合同审批 | 套餐/合同变更 | 商务团队 | 超时保留当前状态 |
| 医疗审批 | 涉及健康判断 | 医疗顾问 | 超时默认拒绝 |

## 正则约束保障

| 风险 | 保障机制 |
|---|---|
| 单点耦合爆炸 | 原子使用率 > 80% → 自动拆分建议 |
| 万能路由 | 链路覆盖度 > 60% → λ₃ 自动调大 |
| 拓扑膨胀 | Agent > 5 → 需要证据支撑 |
| 回归失败 | 旧样本通过率 < 95% → 自动回滚 |
| 幻影能力 | 存在依赖验证 → 每次变更后检查 |

## 训练期间的人工审核

| 审核点 | 审什么 | 不审什么 |
|---|---|---|
| 聚类确认 | 分类是否合理 | 不审个体样本 |
| 初始方案 | 工具清单和安全边界 | 不审实现细节 |
| 每轮更新 | 要改什么、方向对不对 | 不审每个失败样本 |
| λ 调节(>±20%) | 权衡是否接受 | 不审计算过程 |
| 最终交付 | 是否批准部署 | 不审每个测试结果 |
